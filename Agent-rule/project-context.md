# Project Context

## 项目定位
- 本项目是本地运行的资源管理器，不是阅读器。
- 系统目标是统一管理与检索本地书籍与漫画资源，提供稳定索引与快速展示能力。

## 管理对象
- PDF / EPUB / HTML / Markdown / FB2 / DOCX 文件（Library）
- TXT 文件（Text Novel）
- 漫画文件夹与 CBZ 压缩包（Comic；以目录或归档文件为资源单元）

## 核心流程
1. 扫描目录并识别资源实体。
2. 建立与更新本地索引。
3. 解析文件名与目录名，提取元数据。
4. 生成封面候选与缩略图并写入缓存。
5. 将结构化数据提供给 UI 展示与交互。

## 非目标
- 不实现内置阅读器能力。
- 不承担在线内容抓取与云端同步。
- 不以 UI 层直接执行文件系统扫描。

## 优先级
1. 本地优先
2. 性能优先
3. 可维护性优先
