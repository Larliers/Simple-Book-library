## WebEngine 玻璃拟态 UI 重写（路线B）

以 `Simple-Book-library-Dev_Document/UI/新UI/glassmorphism-ui.html` 为范本，将 UI 层从纯 QSS 扁平风重写为 `QWebEngineView` 承载的玻璃拟态 Web 前端，`QWebChannel` 双向桥接现有 Python 后端，内建完整日/夜主题引擎与动态交互动效。`library/` 后端与数据结构未改动。

## 新增

- `src/bookhub/ui/web_scheme.py`：`app://` 自定义 scheme；`register_app_scheme()`（QApplication 前调用）、`to_local_path()`、`AppSchemeHandler`（静态资源 + 封面图白名单代理，越权拒绝）。
- `src/bookhub/ui/web_bridge.py`：`UiBridge(QObject)`；Slots 覆盖 bootstrap/搜索/建议/详情/打开/收藏/合集/标签/设置/主题/根目录/扫描/缩略图/字体/错误日志；Signals 推送 resourcesChanged/toast/scanProgress/scanState/settingsChanged/errorLogsChanged/languageChanged；内置库/文本双 `LibraryViewModel`。
- `src/bookhub/ui/web_window.py`：`WebAppWindow`；QWebEngineView + QWebChannel 装配，worker 编排、原生 QFileDialog/TextRuleDialog、字体与设置写库。
- `src/bookhub/ui/web/`：`index.html` + `css/app.css`（玻璃 + 全部动效 + 日/夜主题变量）+ `js/app.js`（路由/渲染/详情/搜索/右键/toast/设置/主题引擎/模态）+ `js/qwebchannel.js`（Qt 官方原样内置）。
- `src/tests/test_web_bridge_smoke.py`：5 条用例（bootstrap 全页、search 载荷、主题持久化、web 资源存在、file:// 归一化）。

## 改动

- `src/main.py`：入口切换为 `WebAppWindow`；创建 QApplication 前设置 `AA_ShareOpenGLContexts` 并注册 `app://`。
- `src/bookhub/i18n/locales/zh-cn.json`：补齐 Web UI 新增 i18n 键（设置项、主题、菜单、详情、通用等）。
- `scripts/build_nuitka.ps1`：新增 `--include-data-dir=src\bookhub\ui\web=...` 与 `--include-qt-plugins=all` 以携带 QtWebEngine 运行时。
- `src_construction.md`：插入 web 层结构与组件说明，更新时间戳与关键实现注释。

## 决策

- 复杂 Text Rules 规则编辑仍复用原生 `TextRuleDialog`（经 Bridge 调起），简单弹窗（Add Tag / Quick Add / New Collection）用 Web 模态重写。
- `PySide6==6.6.1` 元包已内含 QtWebEngine，未新增 pip 依赖。
- 旧 `app_window.py`/`pages/`/`widgets/`/`styles.py` 保留（供复用与回退），未删除。
