## Text Novel 规则页面卡片化优化

- 根因：原 `TextRuleDialog` 将所有 step 参数同时平铺展示，source、step type、regex、分组、分隔符、括号类型等控件噪音过高，1320px 下仍显拥挤。
- 将字段选择改为左侧竖向 Tab，左列只保留当前字段规则链。
- 将步骤编辑改为中列卡片式表单，每个 step 只展示当前类型需要的参数；`trim`、`remove_extension` 显示“无需参数”。
- 将 source 固定到中列顶部，变更后即时更新当前内存规则并刷新预览；保存时仍沿用原 rules_json 写回。
- 右侧保留常驻预览，并用成功/失败状态框突出结果；失败时显示失败步骤和错误原因。
- 快速模板移动到中列底部，降低对主编辑流程的干扰。
- 补齐 `text.rules.steps.empty`、`text.rules.step_card.title`、`text.rules.step.no_params`、`text.rules.preview.status.*` 文案。
- 新增 `src/tests/test_text_rule_dialog.py`，覆盖旧 JSON 加载、字段切换、上下文参数显示与非法正则失败预览。
- 同步更新 `src_construction.md` 的测试列表与 `text_rule_dialog.py` 职责说明。

## Text Novel 规则步骤能力扩展

- 新增 `take_line`、`take_first_lines`、`take_before_marker`、`take_after_marker` 四类规则步骤。
- `take_line` 支持从 `txt_head_text` 提取第 N 行；`take_first_lines` 支持提取前 N 行。
- 分界线步骤支持以指定文本为界，提取前/后全部内容，或按行/字符提取指定数量；返回结果不包含分界文本。
- `TextRuleDialog` 步骤下拉加入新类型，并按 step type 显示 `index`、`count`、`scope`、`unit` 等上下文参数。
- 当分界线步骤选择“全部”时，数量控件禁用，避免误解。
- 更新 `TextRuleHelpDialog` 与 `zh-cn.json`，说明新步骤建议搭配 `source=txt_head_text`，且受 Settings 文本预览长度限制。
- 扩展 `test_rule_engine.py` 与 `test_text_rule_dialog.py`，覆盖新步骤执行、失败路径和 UI 参数写回。
- 同步更新 `src_construction.md` 中规则步骤处理职责说明。
