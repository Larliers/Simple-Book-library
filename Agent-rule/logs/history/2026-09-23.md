## 集合规则自动归档

- Book、Text Novel、Comic 合集均可维护独立、默认关闭的来源原名规则；一个资源可进入所有命中合集。
- 数据层加入 versioned rule JSON、manual/rule 双来源和排除生命周期；旧成员迁移为手动来源。
- 保存必须先预览；关闭规则必须选择撤销自动成员或保留并转为手动；配置与成员变化原子提交。
- 扫描完成后按 scope 自动重算；失败保留扫描结果并写统计、warning 和错误日志。
- UI 提供合集卡片右键模态及 Settings 双栏管理，共用编辑器、分页预览、排除恢复和定向回写。
- Glass/Vaporwave 共用 740px/600px 响应式结构；未改变既有双击启动入口，未新增运行时依赖。
- 完整实现验证与 GUI 证据见 `../evidence/2026-09-23-collection-rules-gui.md`。
