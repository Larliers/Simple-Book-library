## Text Novel 规则弹窗第一轮优化

- 根因：预览区长文本若由普通文本控件参与布局计算，容易把 `TextRuleDialog` 高度撑开；同时单个 step type 下拉已承载过多规则，查找成本高。
- 将步骤选择改为“类别 / 步骤”两级下拉，底层仍保存原有 `{type, params...}` JSON。
- 新增文本清洗/删除/截取类步骤：`normalize_spaces`、`remove_all_spaces`、`normalize_punctuation`、`remove_text`、`remove_regex`、`remove_bracket_content`、`remove_brackets_keep_content`、`take_before_last_text`、`take_after_last_text`。
- 预览结果区保留项目 `TextRulePreviewResult` 状态框与全局滚动条样式，不使用裸系统边框；右侧预览列内部增加纵向 splitter，结果区高度可拖动调整。
- 新增 `text_rule_preview_result_height` 设置项，结果区高度通过 `app_settings` 持久化，取消保存规则也会记住 UI 高度。
- 修复数量参数禁用范围：仅分界线步骤在 `scope=all` 时禁用 `count`，不影响“去除后N行”等普通数量步骤。
- 更新 `zh-cn.json`、`TextRuleHelpDialog`、`src_construction.md` 与相关测试。
