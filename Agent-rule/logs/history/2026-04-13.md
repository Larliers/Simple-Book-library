# 2026-04-13 开发日志

## 任务：thumbnail集成 + 自定义书单重构 + 右键快速添加弹窗

### 完成内容

#### 1. collections_page.py — 封面缩略图支持
- `CollectionDetailPage._make_book_card()` 升级：优先加载书籍的真实 `thumbnail_path`（KeepAspectRatioByExpanding + 居中裁剪至 144×170），加载失败时回退至彩色首字母色块。

#### 2. favorites_page.py — 全面重构为"自定义书单"
- 原 Favorites（扁平收藏夹）废弃，改为与 Collections 功能对等的"自定义书单"页面。
- 新增辅助函数 `_load_thumbnail()` / `_fallback_cover()`，统一封面加载逻辑。
- `ReadingListCard`：书单卡片，封面区优先展示书单内第一本书的真实缩略图（180×160），无图时使用首字母色块。
- `ReadingListDetailPage`：书单详情页，每本书显示真实缩略图，支持右键「从书单中移除」。
- `FavoritesPage`：「自定义书单」主页，支持新建/删除/重命名书单，点击进入详情。
- 所有文案改为中文（「+ 新建书单」「← 返回」「确定要删除…」等）。

#### 3. quick_add_dialog.py — 全新右键快速添加弹窗
- 对应 UI 设计文件：`鼠标右键的菜单.html`
- 无边框浮窗，包含两个区块：
  - **标签区**：搜索过滤 + 「+ 创建」 + 流式标签芯片（已有标签自动显示选中状态）
  - **书单区**：搜索过滤 + 「+ 新建」 + 滚动列表（每行显示「添加/已添加」状态）
- 「确认添加」提交：批量写入标签增删 + 书单成员增删。
- `_FlowLayout`：自定义 `QLayout` 子类，实现标签芯片自动换行。

#### 4. repository.py — 标签管理 API 新增
- `get_all_tags()` — 跨所有书籍提取去重标签列表（字母序）
- `add_tag_to_book(book_id, tag)` — 幂等添加标签
- `remove_tag_from_book(book_id, tag)` — 移除指定标签
- `get_book_tags(book_id)` — 获取单本书标签列表

#### 5. library_page.py — 右键菜单重构
- 旧「Add to Favorites」/ 旧「Add to Collection…」入口移除。
- 新增「🏷️ 添加标签 / 加入书单…」→ 打开 `QuickAddDialog`（定位于鼠标位置）。
- 新增 `_open_book_external()` / `_open_book_folder()`：实现真正的文件/文件夹打开逻辑（Win/macOS/Linux）。

#### 6. src_construction.md 更新
- 所有新增/修改模块均已在说明书对应段落注释。
