# 2026-09-15 开发日志

## Quick Add 合集无刷新与快捷创建

- 根因：`setCollectionMembership` 每次写入都广播完整 `resourcesChanged`，前端收到后清空并重建当前 `contentArea`，造成滚动位置丢失和整页刷新感。
- Repository 新增事务化 `apply_collection_membership_changes`，统一校验资源/合集 kind 与 ID，在同一事务内完成同名复用、创建、添加和移除。
- Bridge 新增 `applyCollectionQuickAdd`，返回目标合集页数据与资源详情，不发送全量资源广播；旧成员写入入口同步停止广播。
- Quick Add 搜索无 trim+casefold 同名合集时显示“创建并添加”；普通确认改为一次批量提交，失败保留弹窗，成功只更新合集页缓存和选中详情。
- 普通图书、文本小说、漫画及来源感知页面均不重绘；仅当前合集移除可见资源时保存滚动位置后重绘合集详情。
- 新增 Python/Node 回归，覆盖无刷新写入、三类资源、同名复用、失败无部分写入、创建入口、批量确认、失败留窗与滚动保持。
- 聚焦验证：`pytest src/tests/test_collection_kinds.py src/tests/test_web_bridge_smoke.py -q` → `60 passed`。
- 全量验证：`pytest -q` → `264 passed, 43 subtests passed, 2 failed`；两项失败均为既有 settings 非法字符串归一化用例，与本次改动无关。
- 真实 WebEngine 验收：Glass 740px 与 Vaporwave 600px 均在 `scrollTop=1400` 快捷创建合集；提交前后 `renderGen=2`、`scrollTop=1400`，弹窗关闭且合集缓存即时更新，无横向溢出。
