## 2026-04-12 - 全屏场景可读性修正（Sidebar & View Toggle）

- 任务：修复全屏放大场景下侧边栏字体偏小，以及右上角 grid/list 切换区域出现大方形背景的问题。
- 主要动作：
  - 在 `SidebarWidget` 新增自适应缩放逻辑：根据侧边栏高度动态调整标题/副标题/导航字体与图标尺寸。
  - 新增 `resizeEvent` 触发缩放刷新，保证窗口尺寸变化后实时生效。
  - 调整 `LibraryPage` 的视图切换容器为固定尺寸策略并顶对齐，避免容器随标题区高度被拉伸。
  - 调整样式：去除 `ViewTogglePanel` 背景与边框，弱化按钮方块态。
- 结果：
  - 全屏下侧边栏文本与图标可读性明显提升。
  - 右上角不再出现大面积方形背景块。
- 风险：
  - 自适应缩放上限目前为经验值（1.7），后续可根据不同分辨率再细调。

## 2026-04-12 - Sidebar Tab Hover 样式优化

- 任务：让侧边栏选项卡在鼠标经过/点击选中时呈现更接近 HTML 的 hover 交互反馈。
- 主要动作：
  - 为侧边栏按钮增加专属样式标识 `variant=sidebar_tab`。
  - 在全局样式中新增 `sidebar_tab` 的 `hover/pressed/checked` 三态视觉规则。
  - 将 Sidebar 的字体缩放实现从 `setStyleSheet` 改为 `QFont` 动态设置，避免覆盖 hover 样式。
- 结果：
  - 侧边栏 tab 具备更明显的悬停高亮、按压反馈、选中态。
  - 样式作用域仅限侧边栏，不影响其他页面按钮。
