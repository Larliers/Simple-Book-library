## 2026-09-11 - 快捷键绑定识别鼠标侧键

- 根因：侧键经常到不了原来的录入路径。Chromium 子控件会吃掉 `ShortcutWebView.mousePressEvent`；Windows 常把侧键映射成 `BrowserBack`/`BrowserForward` 或只发 `auxclick`/`WM_APPCOMMAND`，旧逻辑只认键盘 `code` 和 WebView 本体事件。
- 页面侧键补 `button`/`which`/`buttons`、`pointerdown`/`mousedown`/`mouseup`/`auxclick` 去重录入；`BrowserBack` 与 `keyCode` 166/167 归一为 `MouseBack`/`MouseForward`。
- `ShortcutWebView` 给自身和后代装 event filter；Windows 再拦 `WM_XBUTTONDOWN` 与 `WM_APPCOMMAND`，窗口失焦不抢事件。
- 验证：快捷键 Node 脚本与 Bridge 侧键映射/子控件专项。未提交。真机请在设置页点绑定框后按侧键，应显示“鼠标后退键/前进键”。

## 2026-09-11 - 合集退出与进入拆成两个快捷键

- 根因：单一“退出／重入”无法对应浏览器后退/前进；全局最近一项会把书籍合集和小说/漫画合集串在一起。
- 拆成 `exit_collection`（退出当前系列）与 `reopen_recent_collection`（进入最近系列）；设置导航组显示两行，默认仍留空。
- 书籍/小说/漫画合集页会话内各自只记本页最近一次成功打开的系列；页面返回按钮只退出；删除合集只清对应页记忆。
- 非合集页、列表态按退出、详情态按进入分别提示。旧 `toggle_recent_collection` 绑定不迁移。

## 2026-09-11 - 关闭快捷键审查遗留的外部打开事件

- 根因：Codex 快捷键功能已落地，但标准审查 Hard 项未结案——`open_resource` 经 `executeAction` 进入 `openResource`/`_open_external` 后没有合同要求的可追踪事件，随后用量上限中断。
- `UiBridge` 新增 `interactionEvent`；`openResource` 仅在目标文件存在时发出 `open_external`（`event`、`resource_id`、ISO-8601 `timestamp`）。资源不存在或文件缺失不发成功事件。
- 不发明 `open_folder` 新事件名，不落盘、不加前端消费者；测试连接信号断言。
- 验证：快捷键/推荐 Node 脚本通过；Bridge + 封面设置专项 47 项通过。未提交。

## 2026-09-11 - 可自定义快捷键绑定系统

- 根因：资源按钮、右键菜单和合集导航直接调用各自函数，缺少统一动作上下文；退出合集详情后也未保存可重新进入的会话目标。

- 原生 `ShortcutWebView` 拦截鼠标侧键 press/release，阻止 Chromium 网页历史导航，并通过 Bridge 信号进入同一分发器。
- 设置新增“快捷键”页，按导航/当前选中资源分组，提供录入、清除、冲突提示和键帽样式；Glass/Vaporwave 在 2560、1400、1120 三档均无横向溢出。
- 合集切换记录本次启动中最近成功打开系列：详情内退出，详情外重入；删除失效时清空并提示，重启不保留。
