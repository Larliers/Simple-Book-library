# 个人知识书库管理系统 --- 设置页面设计（Settings Specification）

## 概述

本设置系统面向"重度用户 + 高效率工作流"，目标是： -
提供高度可自定义的快捷键体系 - 支持本地书库管理策略配置 - 优化 Tag /
书单 / 阅读器体验 - 提供导入转换能力 - 具备开发者级别调优能力

------------------------------------------------------------------------

## 目录结构

    设置
    ├── 通用
    ├── 快捷键（核心）
    ├── 书库管理
    ├── Tag系统
    ├── 阅读器

    ├── 界面

## 1. 通用（General）

    语言：中文 / English

    启动行为：
        [√] 启动自动打开上次书库
        [ ] 启动最小化

    默认操作：
        默认视图：卡片 / 列表
        默认排序：时间 / 作者 / 自定义

    数据路径：
        书库路径
        封面缓存路径

------------------------------------------------------------------------

## 2. 快捷键（Shortcuts）【核心】

### UI结构

    操作名称        当前快捷键       修改
    --------------------------------------
    打开搜索        Ctrl + K         [编辑]
    添加Tag         T                [编辑]
    加入书单        A                [编辑]
    删除书籍        Delete           [编辑]
    切换视图        Tab              [编辑]

### 功能

-   快捷键录制
-   冲突检测（必须）
-   导入 / 导出配置
-   重置默认

### 高级能力

    g + t → 打开tag面板
    g + b → 回到书库

### 数据结构

``` json
{
  "shortcuts": {
    "open_search": "Ctrl+K",
    "add_tag": "T",
    "add_to_list": "A",
    "delete_book": "Delete"
  }
}
```

## 3. 书库管理（Library）

    扫描目录：
        [选择文件夹]
        自动导入新书（√）

    重复检测：
        文件名 / hash / 元数据

    文件管理策略：
        [ ] 保持原路径
        [√] 统一管理（复制到库）

    元数据：
        自动获取封面（√）
        自动填充作者（√）

------------------------------------------------------------------------

## 4. Tag系统（核心差异）

    Tag行为：
        输入即创建（√）
        自动补全（√）
        显示最近使用（√）

    Tag样式：
        颜色标签（√）
        层级tag（可选）

    批量操作：
        自动合并重复tag

### 高级规则

    如果书名包含 "AI" → 自动加 tag: AI

## 设计原则总结

-   即时生效（无"保存按钮"）
-   支持重置（单项 / 全部）
-   高效操作优先（快捷键驱动）
-   模块化配置结构
-   可导入导出配置
