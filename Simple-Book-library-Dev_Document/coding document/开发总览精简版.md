# 本地图书/漫画管理器——开发总览（精简版）

## 一、项目本质

这是一个：
👉 本地资源管理器（不是阅读器）

管理对象：
- PDF / TXT / Word
- 漫画文件夹（图片集合）

核心目标：
- 管理 + 展示 + 快速打开

---

## 二、技术核心

本项目本质是三件事：

1. 文件系统
- pathlib / os.walk

2. 缩略图系统（关键性能点）
- Pillow
- hashlib（缓存命名）

3. UI系统
- PySide6 / PyQt6

---

## 三、UI开发模型

Qt UI =
👉 Widget（组件） + Layout（布局） + QSS（样式）

对应前端：
- Widget ≈ HTML组件
- QSS ≈ CSS
- 信号槽 ≈ 事件监听

关键差异：
- 没有HTML
- 没有flex/grid
- 布局必须用代码控制

---

## 四、核心库（MVP足够）

必须：
- pathlib / os
- sqlite3
- Pillow
- PySide6
- logging
- re

推荐：
- natsort（图片排序）
