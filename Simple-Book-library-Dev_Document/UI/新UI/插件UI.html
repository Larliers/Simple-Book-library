Metadata Fetcher

Version 2.4.1 Windows 10/11 Compatible

Description

Automatically retrieves and updates book metadata, including high-resolution covers, blurbs, and author information from global databases. This tool integrates seamlessly with your local library to keep every entry accurate and aesthetically pleasing.

The Metadata Fetcher supports over 20 different sources and can be scheduled to run background updates. It features an advanced matching algorithm that can identify books even with incomplete titles or incorrect author names.

Features

  • check_circle High-resolution cover art synchronization
  • check_circle Multi-language support for international editions
  • check_circle Automated series grouping and numbering
  • check_circle Customizable data fields mapping
