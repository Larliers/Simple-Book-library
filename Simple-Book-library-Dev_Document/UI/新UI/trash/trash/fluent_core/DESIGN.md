# Design System Document

## Theme Overview
This document outlines the core aesthetic and functional principles of our design system, reflecting a clear and modern user experience.

## Brand Identity

### Colors
Our color palette is built around a professional and consistent brand identity.
- **Primary Color:** `#0078D7` - A vibrant blue, used for primary calls to action, interactive elements, and key branding.
- **Secondary Color:** `#767676` - A neutral gray, supporting less prominent UI elements and secondary actions.
- **Tertiary Color:** `#004578` - A deeper shade of blue, providing an accent for highlights, badges, or decorative elements.
- **Neutral Color:** `#F2F2F2` - A light gray, serving as the base for backgrounds and surfaces.

### Typography
We employ a consistent typography system to ensure readability and hierarchy.
- **Headline Font:** Inter - Used for all major headings and titles, providing strong visual impact.
- **Body Font:** Inter - Applied to all paragraph text and general content, ensuring legibility.
- **Label Font:** Inter - Utilized for form labels, buttons, and small text elements, maintaining clarity.

## Visual Attributes

### Roundedness
UI elements feature sharp, angular corners, providing a precise and structured aesthetic. This is achieved with a roundedness value of `0`.

### Spacing
Our design adopts a normal level of whitespace, providing a balanced and comfortable visual experience. This ensures elements are well-separated without feeling overly dense or sparse.
